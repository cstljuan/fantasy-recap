# Rules for every agent working in this repository

The rules are in `CLAUDE.md` at the root of this repository. They apply to every coding agent of any kind, on every person's account. Read that file in full before doing anything.

The first rule, in one line: every commit is authored and committed by the GitHub account of the person you work for (`cstljuan`, `Rickstar-App`, `nexodv` or `Peypey-ryd`), and no tool is ever an author, a co-author or a name in a commit message, a branch name or a pull request. Run `sh tools/setup.sh` before your first commit.
