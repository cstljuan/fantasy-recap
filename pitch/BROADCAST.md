# The broadcast, week 11

This is everything the announcer says during the week 11 game, written out so it can be read in a minute instead of listened to. The lines come from the team's own announcer code (`js/announcer/`), from rules and written lines, not from a language model. The game itself was built by the team's game engine from invented stat lines for real player names, so the plays and the final score (Goblins 17, Pythons 14) are made up. The tendency and "hot lately" remarks use each player's real season and recent numbers from `data/profiles/`. Crowd and music cues are in brackets, the way television captions show them. Big calls are the longer calls the app shows for the top plays.

Rebuild it with `node js/announcer/transcript.js`.
