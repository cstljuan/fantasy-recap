# Fonts used by the design pages

All three families are under the SIL Open Font License 1.1, so they may be shipped with the project. The files here are the Latin subsets from the fontsource packages.

| Family | Use | Files |
|---|---|---|
| Barlow Condensed | Headlines, labels, numerals | `barlow-condensed-latin-600/700/800-normal.woff2` |
| Barlow | Body text | `barlow-latin-400/500/600-normal.woff2` |
| Silkscreen | Small pixel labels and stamps | `silkscreen-latin-400/700-normal.woff2` |
| Jersey 15 | The masked score `--.-` and big pixel numerals | `jersey-15-latin-400-normal.woff2` |
